# MY - Google Drive Bio Link

Website tautan profil (Link-in-bio) dengan background video YouTube dan 2 tombol tautan Google Drive (Tugas Saya & Tugas Kelas).

## Fitur
- **Background Video**: Video YouTube autoplay, looping, muted (ID: `XpIKBdEnnFw`).
- **Glassmorphism UI**: Desain modern kartu profil transparan responsif.
- **Tombol Tautan**:
  - `Tugas Saya`
  - `Tugas Kelas`
- **Profil**: Foto avatar profil MY.

## Cara Mengganti Link Google Drive
Buka file `index.html`, cari baris:
```html
<a href="https://drive.google.com/" ...>
```
Ganti `https://drive.google.com/` dengan link folder Google Drive yang diinginkan.
